Pembuat kunci lama v11 (offline)

Tetap tersedia untuk kompatibilitas kunci v11 yang sudah ada. Untuk kunci baru yang bisa dikelola (blokir dan batas perangkat), gunakan pembuat kunci online di bawah.

Riwayat kunci lama v11

Riwayat kunci offline ini tersimpan di browser ini saja. Kunci online tersimpan di server dan dikelola pada dashboard di atas.

Ganti passphrase

Menghasilkan file admin baru yang dikunci dengan passphrase baru. Simpan file lama sampai file baru teruji.
Catatan penting.
1) Untuk kontrol perangkat dan pencabutan langsung, HP harus tersambung ke internet saat aplikasi memvalidasi lisensi.
2) Kunci baru sebaiknya dibuat melalui "Buat kunci online". Kunci lama v11 tetap diterima dan didaftarkan ke server saat pertama kali dipakai pada aplikasi yang sudah diperbarui.
3) Kunci privat lama tetap tersimpan terenkripsi di file ini. Simpan salinan HTML asli dan passphrase di tempat aman.
