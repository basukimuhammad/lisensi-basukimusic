ℹ️ Panduan Sistem Lisensi

Web ini memiliki dua jenis lisensi. Jangan bingung jika melihat ada format kunci yang berbeda:

  • Kunci v11 (BSK-XXXXXX-...): Kunci utama buatan Anda sendiri. Dibuat via tab Buat Lisensi atau v11 Offline. Bisa dijual dan dibaca oleh APK v11.
  • Kunci Web/Trial (BSK2-...): Kunci otomatis dari sistem web untuk user yang klik "Ambil Trial". (Contoh: email mbasuki3321@gmail.com di bawah). Anda bisa memblokir atau menghapusnya jika mengganggu.

Buat / Daftarkan Kunci v11

Pilih untuk membuat kunci baru secara otomatis, atau mendaftarkan kunci yang sudah ada (dibuat offline) agar bisa dipantau di dashboard dan terhubung ke email pembeli.

Pembuat kunci v11 (offline)

Kunci dibuat 100% di browser, tanpa koneksi server. Cocok untuk backup / dijual offline. Kunci akan otomatis terdaftar ke server saat pertama kali diaktifkan di APK.

Ganti passphrase admin

Menghasilkan file HTML admin baru yang dikunci dengan passphrase baru. Simpan file lama sampai file baru teruji.

Catatan penting

1) HP harus online saat APK memvalidasi lisensi — untuk blokir & manajemen perangkat.
2) Kunci v11 lama tetap diterima dan didaftarkan ke server saat pertama dipakai di APK yang sudah diperbarui.
3) Private key tersimpan terenkripsi di file HTML ini. Simpan HTML asli + passphrase di tempat aman.
